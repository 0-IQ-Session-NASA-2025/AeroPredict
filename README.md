### Setup Git Hooks to follow the git conventions

After cloning the repository, run the setup script to install git hooks:

```bash
chmod +x scripts/setup-hooks.sh
./scripts/setup-hooks.sh
```

This will install pre-commit, commit-msg, and pre-push hooks to enforce code quality and commit conventions.
